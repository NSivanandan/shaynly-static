    ⚡ Bulk URL Processing

    • Add URLs individually or paste lists from spreadsheets
    • Real-time URL validation with error highlighting
    • Drag-and-drop URL reorganization

    ⚙️ Granular Control

    • Set individual priorities (0.0-1.0) and change frequencies
    • Batch-set last modified dates to current date
    • Custom defaults for new entries

    ✅ Smart Validation
