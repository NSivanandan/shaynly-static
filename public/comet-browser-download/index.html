Introduction: The Dawn of the AI Browser

What is the Perplexity Comet Browser?

The Perplexity Comet browser represents a significant evolution in web technology, moving beyond the traditional model of a passive window to the internet into an active, intelligent, and collaborative partner in online tasks. Officially announced by Perplexity AI in July 2025, Comet is an "AI-native" browser built on the robust Chromium architecture, ensuring compatibility with existing web standards and extensions.

Key Innovation

Unlike conventional browsers that simply display, Comet integrates a powerful AI assistant directly into its core, designed to understand, synthesize, and act upon the content you encounter.

Security and Privacy Considerations

Security Vulnerability Disclosure

The "CometJacking" vulnerability was discovered and reported in October 2025. Perplexity has since addressed this issue, but it highlights the importance of security in AI-native browsers.

The "CometJacking" Vulnerability

Understanding Indirect Prompt Injection

CometJacking exploits the browser's core functionality through indirect prompt injection, where malicious actors embed hidden prompts in URLs or web pages [157].

Attack Mechanism:

  • • Malicious prompt embedded in URL parameters
  • • Base64 encoding used to obfuscate commands
  • • AI mistakes malicious prompt for user instruction

Potential Risks

Successful attacks could expose sensitive personal and corporate data, including emails, calendar appointments, and documents [155].

Personal email exposure
Calendar data access
Document theft

Frequently Asked Questions

How does the Perplexity Comet browser handle my data?

The browser integrates with services like Gmail and Google Calendar to provide AI-powered features. Perplexity prioritizes privacy by using local storage for sensitive data when possible and implementing strict access controls. However, to perform tasks like summarizing emails, data must be processed, which may involve sending it to Perplexity's servers. The privacy policy provides detailed information about data collection, usage, and protection.

Is the Perplexity Comet browser safe to use?

While the CometJacking vulnerability was discovered and addressed, users should always keep the browser updated to the latest version for security patches. It's important to be cautious about permissions granted and avoid clicking links from untrusted sources. As with any AI assistant handling sensitive data, there are inherent security considerations that users should be aware of.

Can I import my data from other browsers?

Yes, since Comet is built on the Chromium platform, you can easily import bookmarks, history, passwords, and settings from other Chromium-based browsers like Chrome or Edge. The import process is typically prompted during initial setup or can be accessed through the browser's settings menu.

What are the main differences between free and paid versions?

The free tier includes core features like the AI assistant, conversational search, and cross-tab intelligence. Paid versions (Perplexity Max and Comet Plus) offer more powerful AI models, unlimited AI tasks, priority support, advanced integrations, and detailed analytics. The premium features are designed for power users and professionals requiring advanced capabilities.

How does the AI in the Comet browser work?

The AI is powered by a combination of Perplexity's own models and advanced LLMs like GPT-4 and Claude 3.5. These models understand natural language, maintain conversation context, and perform complex reasoning. The AI is deeply integrated into the browser's architecture, allowing it to interact with web pages, synthesize information from multiple sources, and learn from user habits to provide increasingly personalized assistance.
