n IIn Understanding the January 2026 Glitchn

n n

n Google Incident NNnDkY9CJ36annsfytjQ is not a single bug, but a "perfect storm" of overlapping technical issues within the Gmail delivery pipeline. n

nn
n n
n
n n
n

Tab Bypass

n

Classification metadata is failing to attach to incoming SMTP headers, causing Gmail to default all mail to the Primary tab.

n
n n
n
n n
n

Scanning Errors

n

The red banner warning "Gmail hasn't scanned this message..." appears on legitimate mail due to a timeout in the sandboxing layer.

n
n n
n
n n
n

MTA Latency

n

Mail Transfer Agents (MTA) are experiencing massive backlogs, causing delivery delays ranging from 20 minutes to 4 hours.

n
n
nn

Why is this happening now?

n

n Google recently migrated its entire spam-detection infrastructure to a decentralized processing model. On Jan 24th, a configuration error in the "Categorization Node" led to a failure in the logic that routes mail to Promotions and Social tabs.n

The RETVec AI Algorithm

n

n Gmail's new RETVec (Resilient Entirely-convolutional Text Vectorizer) is a massive upgrade over traditional spam filters. It is designed to "read" the visual structure of an email rather than just looking for keywords like "SALE" or "OFFER.n

n
n

How RETVec Works:

n
    n
  • n n Visual Understanding: It detects text hidden within images or stylized characters (e.g., "v1agra" vs "viagra").n
    • n
  • n n Contextual Layering: It analyzes the relationship between the sender's history and the recipient's response rate.n
    • n
  • n n The Current Problem:n During the Jan 2026 incident, RETVec's "Confidence Threshold" was reset to 0, meaning it treats every authenticated email as "High Importance" by default.n

n IVn Step-by-Step Troubleshooting Guiden

nn
n n
n

1. Check Service Status

n

Before changing settings, verify if the glitch is still active in your region. Visit the Google Workspace Status Dashboard and look for Incident #NNnDkY9CJ36annsfytjQ.

n
n n
n

2. Enable Smart Features

n

The AI categorization engine requires "Smart Features" to be toggled ON. Sometimes a core update toggles this off.

n
n Settings > General > Smart features and personalization > [Check ON]n
n
n n
n

3. Disable "Never Send to Spam" Filters

n

If you have a manual filter that says "Never send it to Spam" for a specific domain (like @amazon.com), Gmail will currently force that mail into Primary because it cannot decide between the Filter and the broken Category system.

n
n n
n

4. Stop Filter Overrides

n

Prevent Gmail from using past behavior to categorize your mail during the outage.

n
n Settings > Inbox > Importance markers > Select "Don't use my past actions..."n
n
n n
n

5. The "Manual Training" Fix

n

Force the AI to re-learn. On Desktop, drag a promotional email from Primary to Promotions. When the box asks "Do this for future messages?", click YES immediately.

Frequently Asked Questions

n n
n n
n
n Why is my Gmail Primary inbox suddenly full of promotional emails?n n
n
n This is due to a service disruption (Incident NNnDkY9CJ36annsfytjQ) where Gmail's AI categorization engine has stopped correctly tagging incoming mail with "Promotions" or "Social" labels, causing them to default to the Primary tab.n
n
n n
n
n What does the "Gmail hasn't scanned this message for spam" warning mean?n n
n
n During the current glitch, Google's high-speed scanning servers are timing out. When this happens, Gmail allows the email to pass through to your inbox but flags it with a warning to exercise caution because it hasn't verified the sender authentication (SPF/DKIM) or malware signatures.n
n
n n
n
n Is the lack of filtering related to the January 2026 Gmailify shutdown?n n
n
n Yes, potentially. Google officially killed Gmailify and legacy POP3 this month. If you are viewing Yahoo or Outlook mail through Gmail, those external emails will no longer be processed by Google's advanced spam AI, leading to an unfiltered mess in your inbox.n
n
n n
n
n How do I "re-train" my Gmail filters after this glitch?n n
n
n Once the service stabilizes, you can re-teach the algorithm by dragging and dropping a miscategorized email from the Primary tab to the Promotions tab. Click "Yes" when asked if you want to do this for all future messages from that sender.n
